# KnowledgeHub E-Learning Platform

KnowledgeHub is a full-stack e-learning web application built with **Spring Boot (backend)** and **vanilla HTML, CSS, JavaScript (frontend)**.

---

## 🚀 Features

* Modern UI with glassmorphism design
* Course Enrollment System
* Resume Learning from last position
* Dynamic Dashboard (real-time stats)
* Learning Streak tracking 🔥
* Course Progress tracking
* Interactive video-based courses
* User Profile & Account Management

---

## 🏗️ Tech Stack

* **Backend:** Spring Boot (Java)
* **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
* **Database:** SQLite 
* **Authentication:** JWT-based login system

---

## ⚙️ How to Run the Project

### 1. Run Backend (Spring Boot)

Navigate to backend folder:

```bash
cd spring-backend
```

Run the application:

```bash
mvn spring-boot:run
```

OR run from IDE (IntelliJ / Eclipse)

Backend runs on:

```
http://localhost:8080
```

---

### 2. Run Frontend

Open frontend:

```bash
cd frontend
```

Run using local server:

```bash
npx serve .
```

OR simply open:

```
frontend/index.html
```
